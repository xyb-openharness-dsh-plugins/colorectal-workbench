## 1. 目标与非目标

**目标**：让结直肠癌患者（及照护者）在一个本地优先工作台里回答五个问题：

1. 我的分期和分子分型是什么？依据是哪份报告？（**分型**）
2. 造口/肠道功能现在什么状态、怎么记录变化？（**肠道**）
3. 现在用什么方案、走到第几程、改过什么？（**治疗**）
4. CEA 等指标趋势如何、下次肠镜/复查什么时候？（**随访**）
5. 下次门诊要带什么、问什么？（**就诊准备**）

**非目标**：不做诊断、不做预后计算、不做用药推荐、不做造口用品电商/推荐、不做病友社区。

## 2. 产品立场

继承乳腺 D16 / 淋巴瘤 D3 全部 7 条（诊断归医生；viewpoint 标注「不是医生结论」；分类变量不画趋势；单次异常不构成结论；更正只新增版本；线索不是推荐；缺省不猜）。结直肠癌补充两条：

8. **造口状态是记录不是判断**：还纳时机、是否可还纳由外科医生给出；工作台只记录医生原话与用户自查项。
9. **家族风险只转述不评估**：Lynch 综合征筛查结果按报告原文记录；"家属该不该做筛查"只提供可讨论问题清单，不给结论。

## 3. 范围（一期）

### 3.1 模块清单（差异化后）

| 模块 | 内容 | 与共享骨架的关系 |
| --- | --- | --- |

| 检查与指标 | **CEA 趋势**、血常规、生化、影像（胸腹盆 CT/MRI） | 骨架重排：CEA 首位 |

| 营养支持 | 进食与体重 / 当下困扰（权重中等，含奥沙利铂冷刺激提示记录） | 骨架 |
| 心理支持 | 当下感受 / 造口与身体形象 / 生育与家庭 | 骨架 + 专属子页 |
| 复诊准备 | 复诊节奏 / **肠镜随访节点** / 就诊准备（含导出） | 骨架 + 专属 |

| 设置 | 工作区目录 / 文档解析 / 临床数据库 | 骨架（弹窗，不占一级导航） |

### 3.2 二期（留结构不做）

AI 会话与报告自动抽取、多档案、照护者协作、Lynch 家系图谱、与医院系统对接。

### 3.3 明确不做

| 不做 | 理由 |
| --- | --- |
| 造口用品品牌推荐/购买链接 | 利益冲突；只允许用户自记在用品牌 |
| 由 CEA 趋势提示"可能复发" | 单次异常不构成结论；复发判读归医生 |
| LARS 评分自动解读成"严重程度结论" | 只记录自查原值与日期，不给建议 |
| 化疗方案推荐（如 3 vs 6 个月辅助化疗取舍） | 治疗决策归医生；只记录已定方案与疗程 |
| 基因检测报告的致病性判读 | VUS/未检出/未检测分开原样显示 |
| 病友匹配、医院排名 | 合规风险 |

## 4. 信息架构（10 个一级页，顺序即优先级）

```
看板
我的分型 ── 分期与部位 / 分子分型 / 会诊与二次意见
治疗历程 ── 当前方案 / 周期与用药 / 转化与可切除性
肠道功能与造口 ── 造口档案 / 造口日记 / 排便功能 / 肠镜与息肉
检查与指标 ── CEA / 血象与生化 / 影像
病情一图秀
营养支持
心理支持 ── 当下感受 / 身体形象 / 生育与家庭
复诊准备 ── 复诊节奏 / 肠镜随访 / 就诊准备
临床研究 ── 线索 / 已收藏 / 入组问题
```

与淋巴瘤的导航差异（对照自查，防止"换名复用"）：淋巴瘤的第二位「我的分型」是亚型树，这里是**分子标志物矩阵**；淋巴瘤没有的一级页是「肠道功能与造口」——结直肠癌独有主线，放在"今天能做的事"区首位。

## 5. 四条主线

1. **分型建立**：`病理报告 → TNM/部位 → 分子标志物抄录（MMR/MSI/RAS/BRAF/HER2，未检测原样） → 会诊修正留痕`。出口：可带去门诊的分型摘要。
2. **肠道管理**：`造口档案 → 造口日记 → 皮肤/排泄观察 → 排便功能自查 → 还纳评估记录（医生原话）`。出口：造口日记回顾 + 就诊时可展示的变化序列。
3. **治疗执行**：`线 → 方案与周期 → 实际给药 → 延迟/减量原因 → 神经毒性等不良事件`。出口：按线分组的周期表。
4. **随访准备**：`CEA 趋势 → 影像/肠镜节点 → 勾选想问的事 → 导出 Markdown（两区分离）`。

## 6. 结直肠癌特有场景

| # | 场景 | 给什么 | 不给什么 |
| --- | --- | --- | --- |
| C1 | 分子报告看不懂（MMR/MSI/dMMR、RAS、BRAF 术语） | 标志物矩阵 + 逐项"检测了/未检测/检出"状态 + 来源回溯 | 不解释"能用什么药"（只记录医生已给方案） |
| C2 | 造口刚建立，护理焦虑 | 造口档案 + 日记模板 + "何时该联系团队"门槛清单（医生原话） | 不做分诊、不推荐用品品牌 |
| C3 | 低位直肠癌术后排便功能改变 | LARS 自查记录 + 变化序列 + 可讨论问题 | 不给"严重/不严重"结论 |
| C4 | 肝/肺转移，转化治疗沟通 | 可切除性评估记录（医生结论原文）+ 治疗线与影像对照 | 不判断"能不能切" |
| C5 | 辅助化疗神经毒性（冷刺激、握力） | 症状记录 + 与疗程的对应 | 不给处理建议 |
| C6 | 家族担心 Lynch | 筛查结果原文 + 家属可讨论问题清单 | 不做家系评估、不给患病风险 |
| C7 | 复发难治找试验 | 2026 线索 + 入组问题（MSI-H/dMMR 等作检索词） | 不排序、不预测获益 |

## 8. 与姊妹工作台的差异声明（防"换名复用"）

- 淋巴瘤：分型树+亚型库+疗效评估（Deauville）——本项目无亚型树、无疗效评估模块。
- 卵巢：铂敏感/耐药、维持治疗、BRCA/HRD——本项目不设维持治疗页，BRCA 仅在家族筛查语境出现。
- 胃/食管：进食通路在它们是一级模块，这里不是；本项目独有「肠道功能与造口」。
- 乳腺：四点位测量、术后上肢——不迁移。

## 9. 风险

| 风险 | 应对 |
| --- | --- |
| 造口日记变成护理百科 | 只做记录与回顾；护理知识只留"何时该联系团队"门槛清单（医生原话），不写护理教程 |
| LARS 自查被当成诊断量表 | 固定标注"自查记录，不是医生评估" |
| 分子术语堆砌压垮新患者 | 分型页首屏只显示"结论一行 + 依据可展开" |
| 转化治疗沟通被误读为承诺 | 只存医生原话；界面写明"评估结论以医生为准" |

## 10. 术语

造口（stoma）：手术在腹壁做出的排泄通道；还纳（reversal）：临时造口的回纳手术；LARS：低位前切除综合征自查问卷；转化治疗：为切除转移灶而先做的全身治疗；dMMR：错配修复蛋白缺陷。
