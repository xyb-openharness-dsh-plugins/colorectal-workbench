## 2. 冲突的需求

- "记录要全" vs "每天记录要轻"：日记默认三键（用品/皮肤/排泄），文本可选。
- "想知道全部分子结果" vs "看不懂"：首屏一行结论，展开才有明细。
- 照护者代记 vs 患者隐私（心理/身体形象）：私密字段默认不进导出（继承乳腺 D39 fail-closed）。
