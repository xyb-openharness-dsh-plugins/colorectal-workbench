# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：结直肠癌（结肠癌、直肠癌）患者及照护者；不含肛管肿瘤（归小萌宝）

场景：刚确诊面对分期与MMR/MSI/RAS等分子报告看不懂；术后造口或肠道功能改变需要长期记录；肝肺转移患者的转化治疗与可切除性沟通；复诊与肠镜随访节奏管理

核心流程：
1. 选择本机资料目录并导入病理/影像/检验报告
2. 核对候选信息，建立分型与分子分型档案
3. 记录造口状态与肠道功能变化
4. 按治疗线整理方案、周期与标志物趋势
5. 生成复诊与肠镜随访准备材料

完成结果：得到来源可追溯、可核对的个人病程档案：分型与分子依据、造口与肠道功能记录、治疗历程、标志物趋势、复诊准备材料；所有候选信息经用户核对入档，不提供诊断与治疗建议

初始布局选择：business-first

先读取 docs/DESIGN-PROMPT.md，对齐设计者与研究/取舍原则，再逐项完善SPEC。待补：确认来源、Desktop 版本/平台、原型 hash、当前授权与离线/联网边界。

## 用户新增确认（2026-10-18）

- 与胃癌、食管癌、宫颈癌三个新癌种同批启动，采用「样板先行+批量」节奏：结直肠癌为样板癌种，本轮走完整链路（SPEC→HTML demo→2026 临床数据→SQLite），其余三个本轮只到 SPEC 草案。
- 差异化力度定为「中等：共享骨架+专属模块」：每癌种 1–2 个专属一级模块+导航重排+专属字段，不得把同一套分类换名字复用（用户原话要点：'场景核心是对该癌肿的患者关键信息维度，要体现，不能4个内容，分类细节几乎一样'）。
- 结直肠癌专属主线定为「分子分型（MMR/MSI/RAS/BRAF）+ 肠道功能与造口」；营养为通用模块，权重中等。
- 品牌：无专属 Logo，先走 Awareness 深蓝色系+文字标识（Colopal 小畅宝，占位名）；结构预留 Logo 位。
- 参照物：乳腺癌（工程与流程）、淋巴瘤（G1 SPEC+demo 闸口模式）、卵巢癌（2026 临床数据资料包模式）。
- ai-spec 技能本机不存在，用脚手架 SPEC 流程（templates+prompts）替代，文档如实标注。
