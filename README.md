简体中文 · Colopal Colorectal Cancer Workbench

小畅宝（Colopal，占位名）是面向结直肠癌（结肠癌、直肠癌）患者及照护者的 DSH Desktop 本机优先工作台。它帮助用户整理分子分型（MMR/MSI/RAS/BRAF）、记录肠道功能与造口日常、按治疗线回顾方案与标志物趋势，并把复诊要问的问题整理成可携带的清单。医疗内容只用于资料整理和就诊沟通，不替代医生诊断或治疗意见。

### 定义

结直肠癌是结肠或直肠黏膜上皮来源的恶性肿瘤的统称。结肠癌与直肠癌在解剖位置、手术方式、放疗适用与随访节奏上分开处理，所以这台工作台从建档起就把「结肠 / 直肠」分成两条线。

病理诊断与分期是档案的第一层：TNM 分期的口径来自 AJCC（本项目未取得原件）。分子分型是第二层：MMR / MSI、RAS（KRAS/NRAS）、BRAF、HER2 四项在晚期/转移情形下被指南列为必测类别（据 NCCN 患者版 2025 与 CSCO 2025 转引）。本台只把病理与分子报告的原文抄进档案；「缺失」「未检出」「未检测」三态分开记，未检测不等于阴性。肿瘤部位（结肠 / 直肠）与手术方式（是否造口）是随访与生活记录的入口，不是严重程度标签。

### 目前治疗全景概要

按期别与线序列出指南里出现过的手段类别。这是「世界上大致有哪些办法」的地图，不含剂量、疗程与适用条件——那些必须由医生按你的分期、部位与分子结果决定。

- **局限期（可以手术时）**：手术（结肠癌与直肠癌的切除范围与吻合方式不同；是否造口由部位与手术情形决定，本台只记录术式与造口状态）／术后辅助化疗（按分期与病理高危因素分层列出）／直肠癌放疗（新辅助或辅助放疗；本台只记疗程与日期）／非手术等待（直肠癌在特定条件下存在「观察等待」路径，2026 登记里有相关研究；是否适用属医生判断）。
- **局部晚期 / 转移后**：系统治疗按分子分型与线序分组（化疗、靶向治疗、免疫治疗；MSI-H / dMMR 与 RAS、BRAF V600E、HER2 等标志物决定分组，本台只抄报告原文，不替你选组）／肝、肺转移的局部治疗与转化治疗被列出／临床研究被列为正式选项，不是最后手段。
- **贯穿全程**：随访节奏（按分期取值，CEA 与影像间隔在 NCCN 2025 与 CSCO 2025 里都有条目；本台只显示「指南节奏 / 你最近一次 / 参考窗口」，不发提醒）／ctDNA 与 PET（NCCN 2025.V5 明确为「不做常规随访手段（仅限临床试验）」，CSCO 2025 列为可选/有争议；本台呈现为空态说明，不进待办、不画趋势）／造口与排便功能、营养与运动（ESMO Open 2026 有局部期结肠癌术后结构化运动的 Express Update，本台只记「做了没有、感受如何」）。

以上是文献与指南里列出的手段，按病期与线序排列，**不代表任何一项适合你**。选哪一个，这一句需要问你的医生。

## 产品范围（一期规划）

- 分子分型矩阵：MMR/MSI、RAS、BRAF、HER2 各自独立记录，未检测原样显示，不补成阴性；每项可回溯报告原件。
- 肠道功能与造口（专属模块）：造口档案（类型/位置/日期/性质）、三键造口日记（用品/皮肤/排泄，每条约 30 秒，漏记不催促）、LARS 排便功能自查留档、肠镜与息肉随访节点。
- 治疗历程：按治疗线/阶段分组；围手术期方案；转化治疗患者的影像评估与外科结论分列留痕，更正只新增记录不覆盖。
- 检查与指标：CEA 默认第一位的趋势呈现；血象、影像按报告原文摘录。
- 病情一图秀：治疗节点 + 可量化指标，治疗条与数据区分离；分类变量只按节点呈现，不连折线。
- 复诊准备：想问的事与"我的看法"两区分离导出（Markdown）；私密条目默认不进导出。
- 临床研究：本地 2026 临床试验资料包检索，线索不排序、不推荐、不预测获益。

## 数据与能力边界

- 患者数据必须存入用户明确选择的资料目录；导入文件在本机处理，识别字段先作为候选内容展示，用户核对后才写入病情记录。
- `unified_search_trials/research/colorectal-cancer/` 是 2026 年首次公示的结直肠癌干预性研究本地快照（ClinicalTrials.gov，480 条），供离线检索；它不是患者数据，登记不证明有效、安全或开放入组。
- 临床试验搜索结果是查找线索，不代表符合入组条件；试验状态和入排标准应向研究中心核实。
- 工作台不提供诊断、分期判读、疗效评价或处置建议；用户看法与担心按"一条信息"记录，标注"不是医生结论"。
- 原型中全部数据为虚构演示数据，不是真实病例。
