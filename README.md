简体中文 · Colopal Colorectal Cancer Workbench

小畅宝（Colopal，占位名）是面向结直肠癌（结肠癌、直肠癌）患者及照护者的 DSH Desktop 本机优先工作台。它帮助用户整理分子分型（MMR/MSI/RAS/BRAF）、记录肠道功能与造口日常、按治疗线回顾方案与标志物趋势，并把复诊要问的问题整理成可携带的清单。医疗内容只用于资料整理和就诊沟通，不替代医生诊断或治疗意见。

## 产品范围（一期规划）

- 分子分型矩阵：MMR/MSI、RAS、BRAF、HER2 各自独立记录，未检测原样显示，不补成阴性；每项可回溯报告原件。
- 肠道功能与造口（专属模块）：造口档案（类型/位置/日期/性质）、三键造口日记（用品/皮肤/排泄，每条约 30 秒，漏记不催促）、LARS 排便功能自查留档、肠镜与息肉随访节点。
- 治疗历程：按治疗线/阶段分组；围手术期方案；转化治疗患者的影像评估与外科结论分列留痕，更正只新增记录不覆盖。
- 检查与指标：CEA 默认第一位的趋势呈现；血象、影像按报告原文摘录。
- 病情一图秀：治疗节点 + 可量化指标，治疗条与数据区分离；分类变量只按节点呈现，不连折线。
- 复诊准备：想问的事与"我的看法"两区分离导出（Markdown）；私密条目默认不进导出。
- 临床研究：本地 2026 临床试验资料包检索，线索不排序、不推荐、不预测获益。

## 数据与能力边界

- 患者数据必须存入用户明确选择的资料目录；导入文件在本机处理，识别字段先作为候选内容展示，用户核对后才写入病情记录。
- `unified_search_trials/research/colorectal-cancer/` 是 2026 年首次公示的结直肠癌干预性研究本地快照（ClinicalTrials.gov，480 条），供离线检索；它不是患者数据，登记不证明有效、安全或开放入组。
- 临床试验搜索结果是查找线索，不代表符合入组条件；试验状态和入排标准应向研究中心核实。
- 工作台不提供诊断、分期判读、疗效评价或处置建议；用户看法与担心按"一条信息"记录，标注"不是医生结论"。
- 原型中全部数据为虚构演示数据，不是真实病例。
